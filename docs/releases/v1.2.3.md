# v1.2.3 — correction de Contact sur mobile

Base : `main` v1.2.2, commit `3f4551ddfa3f24783a20951425ae94f6b8c5ae3d`.
Branche : `codex/fix-contact-mobile-overflow`. Les trois métadonnées de version
sont alignées sur 1.2.3 ; aucune dépendance n'est modifiée.

À 320 px, la largeur minimale intrinsèque de la carte Facebook élargissait la
colonne Grid de Contact au-delà de son conteneur. La piste utilise désormais
`minmax(0, 1fr)`. Le découpage local existant et les animations restent en place ;
aucun masquage horizontal global n'est ajouté.

Les tests navigateur contrôlent toutes les routes à 320×568 et 568×320, ainsi
que les blocs de Contact à 320, 360 et 390 px. Ils vérifient l'affichage et le
masquage de Google Maps avec une réponse réseau simulée. La CI teste Chrome et
WebKit sous Ubuntu ; ses résultats et durées sur le dernier commit font foi.
